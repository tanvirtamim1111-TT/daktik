# এন্ড্রয়েড অ্যাপ সেটআপ গাইড (Mobile Setup Guide)

আপনার ওয়েব অ্যাপটিকে এন্ড্রয়েড অ্যাপে রূপান্তর করার জন্য নিচের ধাপগুলো অনুসরণ করুন:

## ১. প্রজেক্ট সেটআপ (আপনার কম্পিউটারে)
১. প্রথমে এই প্রজেক্টের সব ফাইল জিপ (ZIP) আকারে ডাউনলোড করে আপনার পিসিতে নিন।
২. আপনার টার্মিনাল বা কমান্ড প্রম্পটে প্রজেক্ট ফোল্ডারে গিয়ে লিখুন:
   ```bash
   npm install
   ```
   এটি সব প্রয়োজনীয় লাইব্রেরি ইনস্টল করবে।

## ২. এন্ড্রয়েড প্রজেক্ট তৈরি করা
১. আপনার টার্মিনালে নিচের কমান্ডটি রান করুন:
   ```bash
   npm run build
   npx cap add android
   ```
২. অ্যাপটি সিঙ্ক (Sync) করার জন্য রান করুন:
   ```bash
   npm run cap:sync
   ```

## ৩. Firebase কনফিগারেশন (খুবই গুরুত্বপূর্ণ)
অ্যাপের মেসেজ এবং লগইন এন্ড্রয়েডে কাজ করার জন্য Firebase-এ কিছু সেটিংস করতে হবে:

১. **Firebase Console**-এ যান ([console.firebase.google.com](https://console.firebase.google.com)).
২. **Project Settings** > **General**-এ গিয়ে 'Add App' বাটনে ক্লিক করে এন্ড্রয়েড আইকনে ক্লিক করুন।
৩. প্যাকেজ নেম হিসেবে দিন: `com.dakghor.app` (এটি অবশ্যই আপনার কোডের সাথে মিলতে হবে)।
৪. এখানে আপনার **SHA-1** ক্য (Key) দিতে হবে। (এটি আপনার পিসিতে Android Studio থেকে পাওয়া যাবে। Android Studio-র ডানদিকের মেনু থেকে `Gradle > app > Tasks > android > signingReport` এ ডাবল ক্লিক করলে আপনি এই কী-টি পাবেন)।
৫. এই প্রজেক্টের মেইন ফোল্ডারে থাকা `google-services.json` ফাইলটি কপি করুন।
৬. এই ফাইলটি আপনার প্রজেক্টের `android/app/` ফোল্ডারের ভেতর পেস্ট করে দিন। (নোট: আপনি ২ নং ধাপে যখন `npx cap add android` রান করবেন, তখনই এই `android` ফোল্ডারটি আপনার পিসিতে তৈরি হবে)।

## ৪. অ্যাপ রান করা
১. এন্ড্রয়েড স্টুডিও ওপেন করুন।
২. আপনার টার্মিনালে লিখুন:
   ```bash
   npm run cap:open
   ```
৩. এন্ড্রয়েড স্টুডিওতে প্রজেক্ট লোড হলে 'Run' বাটনে ক্লিক করুন।

## ৫. সাদা স্ক্রিন (White Screen) সমস্যার সমাধান
যদি অ্যাপ ওপেন করার পর শুধু সাদা স্ক্রিন দেখা যায়, তবে নিচের ধাপগুলো অনুসরণ করুন:

১. **অ্যাসেট পাথ চেক করুন:** `vite.config.ts` ফাইলে `base: './'` আছে কিনা নিশ্চিত করুন (এটি অলরেডি করে দেওয়া হয়েছে)।
২. **বিল্ড ফোল্ডার রিফ্রেশ:** টার্মিনালে নিচের কমান্ডগুলো দিয়ে আবার চেষ্টা করুন:
   ```bash
   npm run build
   npx cap sync android
   ```
৩. **Android Studio-তে Gradle Sync:** যদি Run বাটনে লাল ক্রস (X) থাকে, তবে `File > Sync Project with Gradle Files` এ ক্লিক করুন।
৪. **WebView সমস্যা (পুরাতন মোবাইল):** যদি আপনার এন্ড্রয়েড ভার্সন অনেক পুরাতন হয়, তবে 'Android System WebView' আপডেট করে নিন।

## ৬. সাধারণ প্রশ্ন (FAQ)
*   **নোটিফিকেশন কেন আসছে না?** 
    Firebase কনসোলে Cloud Messaging এনাবল করতে হবে এবং `google-services.json` সঠিক ফোল্ডারে থাকতে হবে।
*   **লগইন কাজ করছে না কেন?**
    Firebase-এ আপনার এন্ড্রয়েড অ্যাপের SHA-1 কি অবশ্যই যোগ করতে হবে এবং Google Login এনাবল করতে হবে।
*   **রান (Run) বাটন কাজ করছে না কেন?**
    আপনার পিসিতে `JAVA_HOME` এনভায়রনমেন্ট ভেরিয়েবল সেট করা আছে কিনা চেক করুন।
